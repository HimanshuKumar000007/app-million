# IISER Smart Prep — Physics Notes (written by Muse)

Notes are written in the exact style of `detailedStudyNotes` in
`app/src/main/java/com/example/data/local/SmartPrepSeedData.kt`
(numbered sections, • bullets, plain-text formulae) so they can be pasted
straight into the matching `ChapterEntity`:

| File | Paste into ChapterEntity id |
|---|---|
| ch01-units-and-measurements.md | `phys_ch_1` → detailedStudyNotes |
| ch02-motion-in-a-straight-line.md | `phys_ch_2` → detailedStudyNotes |
